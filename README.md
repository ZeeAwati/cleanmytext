# CleanMyText

Clean messy text before pasting it into ChatGPT, Gemini, or other AI tools.

## Features

- Clean extra spaces and hidden characters
- Fix broken PDF line breaks
- Fix hyphenated words
- Remove page numbers and PDF artifacts
- Remove Markdown and bullet formatting
- Remove URLs and emojis optionally
- Copy cleaned text instantly
- Download cleaned text as a `.txt` file
- Auto-save and restore drafts
- Works directly in the browser

## Tech Stack

- HTML
- CSS
- JavaScript
- Tailwind CSS

## Live Website

https://cleanyoutext.netlify.app

## Privacy

CleanMyText processes text directly in the browser. No account or backend is required.
